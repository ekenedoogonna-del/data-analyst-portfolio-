STUDENTS PERFORMANCE ANALYSIS 
📊 Project Overview

This project analyzes student performance data using Microsoft Excel. The goal was to clean the dataset, calculate student performance metrics, identify trends, and create a dashboard.

🛠️ Tools Used

* Microsoft Excel
* Data Cleaning
* Excel Formulas
* PivotTables
* Data Visualization
* Dashboard Development

Cleaned Data

Dashboard

A visual presentation of the analysis and key findings.

dashboard/student_dashboard.png

🔍 Analysis Performed

* Cleaned and organized the dataset
* Checked for missing and inconsistent data
* Calculated total scores and percentages
* Identified minimum, maximum, and average scores
* Used PivotTables to analyze performance
* Created a dashboard to visualize the results

📈 Key Findings

The analysis identified differences in student performance and highlighted the highest- and lowest-performing areas.

🎯 Conclusion

This project demonstrates my ability to clean, analyze, and visualize data using Microsoft Excel and communicate findings through a dashboard.
